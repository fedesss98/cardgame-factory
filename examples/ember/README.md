# Ember Station fixture

A second, deliberately different renderer fixture: dark minimal theme, sans-serif
reading font, longer multi-paragraph card text, two chapters, a conditional
follow-up, a fallback ending and one persistent flag. The opening deck is ordered;
the final deck is weighted.

The image is a procedural placeholder, not production artwork. The package ID
`com.example.emberstation` must be replaced before release. This is a schema and
presentation fixture, not a balance-tested game.
