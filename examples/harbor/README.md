# Harbor Council fixture

Four cards demonstrate an ordered deck, a weighted deck, conditional follow-up,
two chapters and triggered/fallback endings. The merchant's right choice offers
the follow-up; either route reaches the storm after two completed choices.

The image is a procedural placeholder, not production artwork. The package ID
`com.example.harbor` must be replaced before release. This is a schema fixture,
not an implemented or balance-tested game. Its failure ending intentionally
illustrates a rule that the short sample cannot normally reach.
